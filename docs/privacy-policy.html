ScribbleTab for Chrome

Zero Data Ingestion

Privacy Policy

ScribbleTab is an on-demand Chrome extension providing an interface to sketch freehand overlays on active websites and snap the resulting visual compilation. This transparency document outlines exactly how data isolation works within the application layers.

Last updated: June 2026

Core Commitment

ScribbleTab strictly operates on a decentralized, zero-telemetry architecture. The application collects no personal identifiers, logs no browsing records, and features no outbound network transmission layers. Your interactions remain isolated within your local machine runtime context.

Data Collection Boundaries

  • No observation or ingestion of tab URLs or persistent browser behavior.
  • No tracking or parsing of data inside target page documents.
  • No deployment of system performance metrics or session monitoring tags.
  • No local cookie storage allocation or user fingerprint configuration.
  • No external cloud pipeline integration for drawing layers or captured assets.

Extension Permission Disclosures

ScribbleTab enforces a strictly restricted security footprint, requesting solely the fundamental browser access hooks required for basic execution:

API Scope Technical Utility
activeTab Grants short-term, programmatic access to hook the rendering canvas overlay onto the currently focused document layout upon explicit user invocation.
tabs Accesses target window identity parameters allowing the background rendering thread to scope capturing bounds specifically to your current active window.
scripting Permits injection sequencing of local library files across running tabs without forcing manual browser refreshing.
clipboardWrite Enables writing raw image buffers onto the system-level clipboard layer when the clipboard action is clicked. This API loop is strictly unidirectional; data is never read.
host_permissions Authorizes canvas mount permissions dynamically across uniform web pages. No contents are processed or stored off-device.

Code Execution Model

The extension operates entirely via statically bundled, local code assets. ScribbleTab completely prohibits remote script loading, runtime string parsing functions like eval(), or external configuration injections, successfully eliminating classic remote cross-site vector threats.

State Lifecycle Management

ScribbleTab features non-persistent, entirely volatile memory operations. Annotations are kept alive directly inside active browser heap space; the application bypasses persistent database engines like chrome.storage, localStorage, or IndexedDB entirely. Terminating the viewport panel instantly cleans up and frees all canvas assets completely.

Third-Party Isolation

There are zero dependencies, software development kits (SDKs), advertising structures, or tracking nodes linked to the application. Data isolation is maintained uniformly against external systems.

Regulatory Alignment

By bypassing the creation of user profiles and data records entirely, ScribbleTab maintains direct design compliance with global privacy mandates including COPPA, GDPR, and CCPA standards.

Revisions and Modifications

Should this document be adjusted to reflect new local browser workflow options, standard revision logs will note updates openly here. Given our structural zero-data architectural footprint, operational shifts impacting privacy standards are fundamentally highly unlikely.
